# LIFE OS

집 PC에서 사용하는 2027 LIFE OS. index.html을 브라우저에서 열면 됩니다.

## 개인 데이터
Git에는 화면 코드와 빈 리뷰 템플릿만 저장합니다. assets/ledger-data.js, 01_FINANCE 원본 폴더, 엑셀은 제외합니다. 기존 PC의 해당 파일을 복사해야 실제 가계부가 표시됩니다. 공개 저장소에 개인 거래 파일을 추가하지 마세요.

## 화면
- 자산취득·거래비용·대출·생활소비·확인 필요를 분리
- 지출의 양수 금액은 원장 부호대로 차감
- 원본 행과 분류 근거 표시, 월·목적·검색 필터, CSV 내보내기
- 2027 생활 기록과 월간 리뷰, 브라우저 저장 및 JSON 백업

분류는 원장 거래명·메모와 기존 분류에 기반한 잠정 분류를 포함합니다. 원금·이자가 구분되지 않은 상환은 별도로 표시합니다. 엑셀 변경은 자동 반영되지 않습니다.
