# LIFE OS

## 웹에서 사용
상단 **가계부 불러오기**에서 기존 뱅크샐러드 .xlsx를 선택하세요. 파일은 브라우저 내부에서 처리하며 외부로 업로드하지 않습니다. 현재 제공된 형식의 2026-01-01~2026-09-13 거래를 지원합니다. 2025년 거래는 제외합니다.

- 목적별 가계부: 자산·대출·생활·확인 필요, 환급 반영, 검색·CSV
- 자산·부채: Excel 재무현황 읽기, 기준일·잔액·포함 여부 수정
- 정리된 Excel 내려받기: 요약·거래내역·자산현황과 합계 수식
- 추천도서·실행 제안: 습관, 집중, AI 업무 활용
- 2027 월간 기록, 전체 JSON 백업·복원

가계부·자산·리뷰는 현재 브라우저에 저장됩니다. 다른 기기에서는 전체 백업 파일을 불러오세요. 서버 동기화나 로그인은 제공하지 않습니다. 공용 PC에서 개인 데이터를 불러오지 마세요.

## 금액 해석
목적별 분류는 거래명·메모와 원본 분류를 사용한 잠정 분류입니다. 대출상환 원금·이자 비중, 지방세 세목, 계좌/종목 중복과 누락 자산은 직접 검토해야 합니다. 자산 기준일은 추측하지 않고 비워둡니다. 파일 총계 0 대신 행별로 재계산합니다.

## Excel
암호 없는 .xlsx, 현재 뱅크샐러드 형식을 지원합니다. 내보낸 검토용 Excel 수정은 웹에 자동 반영되지 않으며, 복원은 JSON 전체 백업을 사용하세요. 원본은 변경하지 않습니다.

## 배포
GitHub Pages main 루트. 변경 커밋을 push하면 자동 배포됩니다. 개인 원본과 거래 데이터는 Git에서 제외됩니다.
