# LIFE OS

## 웹에서 사용
상단 **가계부 불러오기**에서 기존 뱅크샐러드 .xlsx를 선택하세요. 파일은 브라우저 내부에서 처리하며 외부로 업로드하지 않습니다. 현재 제공된 형식의 2026-01-01~2026-09-13 거래를 지원합니다. 2025년 거래는 제외합니다.

- 목적별 가계부: 자산·대출·생활·확인 필요, 환급 반영, 검색·CSV
- 자산·부채: Excel 재무현황 읽기, 기준일·잔액·포함 여부 수정
- 정리된 Excel 내려받기: 요약·거래내역·자산현황과 합계 수식
- 추천도서·실행 제안: 습관, 집중, AI 업무 활용
- 2027 월간 기록, 전체 JSON 백업·복원

가계부·자산·리뷰는 현재 브라우저에 저장됩니다. 다른 기기에서는 전체 백업 파일을 불러오세요. 서버 동기화나 로그인은 제공하지 않습니다. 공용 PC에서 개인 데이터를 불러오지 마세요.

## 금액 해석
목적별 분류는 거래명·메모와 원본 분류를 사용한 잠정 분류입니다. 대출상환 원금·이자 비중, 지방세 세목, 계좌/종목 중복과 누락 자산은 직접 검토해야 합니다. 자산 기준일은 추측하지 않고 비워둡니다. 파일 총계 0 대신 행별로 재계산합니다.

## Excel
암호 없는 .xlsx, 현재 뱅크샐러드 형식을 지원합니다. 내보낸 검토용 Excel 수정은 웹에 자동 반영되지 않으며, 복원은 JSON 전체 백업을 사용하세요. 원본은 변경하지 않습니다.

## 배포
GitHub Pages main 루트. 변경 커밋을 push하면 자동 배포됩니다. 개인 원본과 거래 데이터는 Git에서 제외됩니다.

## INVESTMENT
삼성전자, SK하이닉스, 나스닥100 ETF, 미국 성장기업 ETF를 시작 항목으로 제공합니다. 수량·총 매입금액·총 평가금액·기준일을 직접 입력하고 비중·손익을 확인합니다. 실시간 시세는 제공하지 않습니다. 투자 기록은 전체 JSON 백업에 포함됩니다. 기존 자산 현황에는 자동 합산하지 않습니다.

## 공개 정보 자동 갱신
GitHub Actions의 Refresh public investment data가 평일 한국시간 18:30에 수집·배포합니다. Actions에서 수동 실행도 가능합니다. 최초 적용 시 Settings → Pages → Source를 GitHub Actions로 선택하면 브랜치 기본 빌드와 경합하지 않습니다. 공개 HTML/RSS 및 robots 정책이 허용하는 정보만 수집하고 실패를 표시합니다. 동적 사이트나 RSS 차단으로 일부 출처가 수집되지 않을 수 있습니다. 전체 수집 실패도 0원으로 표시하지 않고 상태를 배포합니다. 실제 사이트의 라이브 수집·배포 성공 여부는 Actions 첫 실행에서 확인해야 합니다.

## LIFE WIKI
기존 위키의 개인 JSON을 설계도 메뉴에서 불러옵니다. 원문·5축 실행 보드·과거 자산 스냅샷은 브라우저에 저장되고 전체 백업에 포함됩니다. 과거 자산이나 차입 한도를 현재 잔액에 합산하지 않습니다.

## 메뉴
돈 · 자산 · 투자 · 월간 리뷰 · 내 계획, 다섯 메뉴로 통합했습니다. 예전 HEALTH/WORK/LIFE 링크는 같은 달의 월간 리뷰로, 추천도서 링크는 내 계획으로 연결됩니다. 기존 저장 키·백업·기록 형식은 유지됩니다.
